# VelaMotion LVGL UI

This application ports the page structure and interaction style of the local
ESPWatch LVGL 9.1 project to the 390x450 Huangshan Pi display on openvela.
It does not include ESP-IDF services, EAF animations, or unlicensed source
assets. All values are generated by a local demo model.

## Pages

After a 1.4 second splash, the UI opens the clock page. Swipe horizontally to
move through the circular page sequence:

```
Clock <-> WiFi <-> Chat <-> Heart <-> Weather <-> Alarm
```

Buttons exercise the replacement LVGL overlays for search, alarm, danger, and
doorbell events. The WiFi page is deliberately retained for the first port;
the public connection setter accepts both WiFi and Bluetooth for the later BLE
integration.

## Build and run

From WSL Ubuntu:

```bash
cd /mnt/d/MyProject/openvela-workspace
cmake --build cmake_out/lckfb_huangshan_pi
```

After flashing, start it from NSH:

```text
nsh> velamotion_ui
```

Press Ctrl+C to stop. Do not run `lvgldemo` or another LVGL application at the
same time because the display port permits one LVGL owner.

## Integration API

`ui/velamotion_ui.h` provides setters for time, connectivity, health, weather,
alarms, and notification overlays. Future BLE, IMU, and ai_agent modules must
update the UI through those functions instead of accessing LVGL objects. The
setters currently run in the LVGL thread; background services should marshal
their updates into that thread before calling them.
